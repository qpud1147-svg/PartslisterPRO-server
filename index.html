Runs when generating a listing without a part number. Placeholders: {TITLES_BLOCK} {TITLES_INSTRUCTION} {NP_MAKE} {NP_MODEL} {NP_COLOR} {NP_LOC}

Interchange Field

Controls how the Interchange Part Number field is populated. Leave empty to disable. If empty, the field will not be populated at all.

Tokens: {interiorYears} {years} {keywords} {make} {model} {partNumber} {location} — filled left to right up to 65 chars. Use {interiorYears} to exclude the first and last year (already in the title).
Placeholders: {years} {keywords} {make} {model} {partNumber} {location} {title}

Visual Match Pool

Use the Visual Match button (below the search buttons in either mode) to open a pool overlay of the fetched eBay listings. The AI compares your uploaded photo against each listing thumbnail and pre-sorts them into Matched and Flagged tiers. You pick which listings to use before the title and category are generated. This makes listings more accurate when the same part number covers different physical variants (finishes, logo colors, digital vs analog, optional features, quantity).

Use {N} where the listing count should appear. The AI is told to return a JSON array of match verdicts — keep that instruction if you edit this.
