If something breaks

  1. Run the checks above. A red row says what’s broken and how to fix it. Most fixes are “Reconnect eBay” (⚙ Settings → Admin) or a key in ⚙ Settings → Account.
  2. Is it them, not you? Check Railway’s status page (the server) and eBay’s API status. If they show an outage, wait it out — nothing on your side needs fixing. After a Railway outage, press Redeploy on the newest deployment.
  3. Did an update go wrong? Look at “Files on the server” above. A wrong version means the upload didn’t replace that file — delete the old copies in Downloads, download it again, upload, and check line 1 on GitHub.
  4. Go back to the last working version (2 minutes): Railway → your PartsLister service → Deployments → find the last one that worked (by date) → click its ⋯ → Redeploy. The site runs that older version right away. Your data isn’t touched. The next upload from GitHub replaces it again.
  5. Still stuck? Click Copy report and paste it to Claude. It lists every check and error, but never your keys.
